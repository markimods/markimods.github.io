# Architecture

This project is deliberately split into a static WebKit host and research data.

```text
GitHub Pages
    |
    +-- index.html
    +-- JavaScript runtime tests
    +-- firmware profile
    |
    +-- future research modules
```

The repository does not claim a kernel exploit for 13.02.

When a future, independently verified research component exists, it should be added as a separate module with documentation and reproducible tests.
